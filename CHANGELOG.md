# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-05-30

### Added

- Initial **Ether Dark** theme generated from design tokens
- Token-driven build pipeline using chroma-js
- Auto-discovered palette files in `src/palettes/` (no registry file)
- Build, validate, test, package, and publish scripts
- F5 Extension Development Host debugging support for VS Code and Cursor
